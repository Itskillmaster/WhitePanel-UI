## ✦ Зачем WhitePanel?

Большинство прокси-сборок — это полупереплетённые скрипты: один для пользователей, другой для подписок, третий для бота, а всё остальное в текстовом файле.

**WhitePanel** собирает всё это в **одну операционную панель** — и работает одинаково хорошо на чистом VPS и в контейнерной среде, где публичное доменное имя становится известно только *после* деплоя.

### Осможности

| Раздел | Что даёт |
|---|---|
| 👤 **Пользователи** | Создание и управление аккаунтами, лимитами, трафиком, ссылками |
| 🔗 **Подписки** | Страницы подписки, ссылки конфигов, QR-коды и быстрое копирование |
| 🛰 **Ноды** | Управление нодами, health check, refresh и sync |
| 🧪 **Сканер** | Инструменты TCP / IP / SNI, списки результатов и удобный вывод |
| 🤖 **Telegram-бот** | Настройка бота, автоматизация каналов и воркфлоу продаж |
| 🛒 **Sell Bot** | Тарифы, чеки, ручное подтверждение и выдача подписки |
| 🟢 **Истечение** | Автоматическая обработка истечения и очистка устаревших аккаунтов |
| 🛠 **Инструменты** | Runtime-информация, воркеры, статус туннеля и служебные эндпоинты |

> **Фиксированный порт панели: `8080`.** Запомните один раз — и больше никогда не ищите.

## Вариант A — установка на VPS одной командой

Запустите установщик на поддерживаемом Linux VPS:

```bash
bash start.sh install
```

Установщик занимается зависимостями, файлами приложения и управлением рантаймом. Сама панель слушает на **порту `8080`**.

### Полезные переменные установщика

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `WHITE_APP_DIR` | `/opt/WhitePanel` | Каталог приложения |
| `WHITE_REPO` | *(не задан)* | Git-репозиторий для деплоя |
| `WHITE_BRANCH` | `main` | Ветка для деплоя |
| `WHITE_INSTALLER_URL` | URL `start.sh` проекта | Источник установщика |
| `WHITE_UV_VERSION` | `0.12.9` | Версия uv |
| `WHITE_XRAY_VERSION` | `26.3.27` | Версия Xray |

```bash
# деплой конкретной ветки в заданный каталог
WHITE_APP_DIR=/opt/WhitePanel WHITE_BRANCH=main bash start.sh install
```

> 🔒 Не храните секреты в репозитории. Используйте переменные окружения или защищённые настройки сервера.

## Вариант B — Railway

1. Отфоркайте репозиторий в свой аккаунт GitHub.
2. Создайте новый проект Railway из этого репозитория.
3. Пусть Railway соберёт проект по `Dockerfile` / `railway.toml`.
4. Откройте приложение на **порту `8080`**.
5. Создайте публичный домен.
6. Откройте полученный домен и войдите в панель.

### Заметки по Railway

- Процесс приложения слушает `0.0.0.0:8080`.
- `railway.toml` использует тот же фиксированный порт с Uvicorn.
- Определение публичного домена важно: от него строятся URL подписок и пользовательские ссылки.
- Никогда не используйте `localhost` как публичный хост подписки.

# 🧭 Публичный эндпоинт и поток подписки

В WhitePanel есть хелперы публичного эндпоинта, чтобы панель работала, когда финальный домен определяется *после* деплоя.

```text
Panel
  ├─ /white                → главная панель
  ├─ /login                → страница входа
  ├─ /dashboard            → дашборд
  ├─ /link/<uuid>          → страница ссылки пользователя
  ├─ /p/<uuid_key>         → публичная страница подписки
  └─ /api/sub/<uuid_key>   → эндпоинт подписки
```

Также доступны QR-эндпоинты для выдачи конфигов подписки/пользователя.

# 🤖 Автоматизация Telegram

WhitePanel содержит Telegram-воркфлоу для администрирования, работы с каналами и продаж.

### Channel Bot

Channel Bot может создать нового пользователя, сгенерировать подписку + QR, опубликовать материал в настроенный канал и выполнить очистку после успешной доставки.

### Sell Bot

Клиентский путь намеренно простой — простота даёт продажи:

```text
🟢 Мой аккаунт   →   🛍 Товары   →   💬 Поддержка
```

Каждый тариф управляется отдельно и несёт своё название, цену, инбаунд, квоту трафика, срок и префикс пользователей.

Типичный процесс покупки:

```text
/start
   ↓
🛍 Товары
   ↓
Выбор тарифа
   ↓
Реквизиты оплаты
   ↓
Загрузка чека
   ↓
Проверка админом
   ├─ ✅ Одобрить → Подписка + QR
   └─ ❌ Отклонить
```

Также поддерживаются обязательная подписка на канал, числовые Telegram ID админов, управление тарифами и обработка истечения.

# 🛡 Аккаунт, срок действия и доставка

### Идентификация аккаунта

Процесс продажи связывает клиента с **числовым Telegram ID**. Существующие аккаунты обновляются, а не дублируются, и активация заказа устроена так, чтобы одну покупку нельзя было применить дважды.

### Истечение

Когда срок пользователя заканчивается, expiry sweeper пытается удалить аккаунт, очистить его Telegram-маппинг и сообщить пользователю об истечении.

### Безопасность доставки

Активация и доставка намеренно разделены: временный сбой доставки в Telegram **не** означает, что аккаунт задублирован или что прежний аккаунт ошибочно помечен как удалённый.

# 🔎 Сканер

Раздел сканера включает:

- проверки TCP / IP
- данные подсетей Cloudflare
- списки и проверки SNI
- обработку результатов сканирования IP/SNI
- пакетный ping
- поиск быстрейшего результата

Мобильный интерфейс компактный и «пальцевый»: домен или IP можно тапнуть и сразу скопировать.

# ⚙️ Работа и API

Бэкенд построен на **FastAPI / Uvicorn** и содержит эндпоинты авторизации, пользователей, подписок, нод, сканеров, воркеров, настроек Telegram-бота и runtime-информации.

Docker-образ открывает панель на:

```text
0.0.0.0:8080
```

Для чистого деплоя привяжите публичный домен платформы к этому порту приложения.

# 🎨 Детали интерфейса

Интерфейс построен вокруг:

- адаптивной тёмной/светлой темы — чистый чёрный фон и бирюзовый акцент `#00e1c1`
- компактных сенсорных взаимодействий
- удобного копирования конфигов
- сворачиваемых секций
- страниц подписок с выдачой QR
- Telegram-стиля «стеклянных» кнопок
- раскладок для десктопа и мобильных

Каталог `svg/` содержит исходную графику документации. Это самостоятельные SVG-файлы — визуальная идентичность проекта без растровых скриншотов — и они перекрашены под живую тему панели.

# 🧑‍💻 Разработка

Локальный запуск:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m uvicorn main:app --host 0.0.0.0 --port 8080
```

Затем откройте:

```text
http://127.0.0.1:8080/white
```

Для продакшена и публичных подписок используйте реальный домен вместо `127.0.0.1` / `localhost`.
