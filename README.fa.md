## ✦ چرا WhitePanel؟

بیشتر زیرساخت‌های پروکسی یک مشت اسکریپت نیمه‌وصل‌اند: یکی برای کاربران، یکی برای اشتراک‌ها، یکی برای بات، و بقیهٔ کارها هم داخل یک فایل متنی.

**WhitePanel** همهٔ این‌ها را در **یک سطح مدیریتی** جمع می‌کند — و هم روی یک VPS خام کار می‌کند، هم روی محیط‌های کانتینری که دامنهٔ عمومی تا بعد از استقرار مشخص نمی‌شود.

<div align="center" dir="ltr">
  <img src="svg/features.svg" alt="WhitePanel features" width="100%" />
</div>

### امکانات اصلی

| بخش | چه چیزی به شما می‌دهد |
|---|---|
| 👤 **کاربران** | ساخت و مدیریت حساب، محدودیت، حجم، لینک و عملیات کاربری |
| 🔗 **اشتراک** | صفحهٔ اشتراک، لینک کانفیگ، QR Code و کپی سریع |
| 🛰 **نودها** | مدیریت نود، بررسی سلامت، Refresh و Sync |
| 🧪 **اسکنر** | ابزار TCP / IP / SNI، لیست نتایج و خروجی قابل کپی |
| 🤖 **تلگرام بات** | تنظیم بات، اتوماسیون کانال و فرایند فروش |
| 🛒 **بات فروش** | پلن، رسید، تأیید دستی و تحویل اشتراک |
| 🟢 **انقضا** | مدیریت خودکار انقضا و پاک‌سازی حساب‌های منقضی |
| 🛠 **ابزارها** | اطلاعات Runtime، ورکرها، وضعیت تونل و اندپوینت‌های کمکی |

> **پورت ثابت پنل: `8080`** — یک بار حفظ کن، دیگر دنبالش نگرد.

## گزینه A — نصب تک‌دستوری روی VPS

روی یک VPS لینوکسی پشتیبانی‌شده اجرا کنید:

```bash
bash start.sh install
```

اینستالر وابستگی‌ها، فایل‌های برنامه و مدیریت Runtime را انجام می‌دهد. خود پنل روی **پورت `8080`** گوش می‌دهد.

### متغیرهای کاربردی نصب

| متغیر | مقدار پیش‌فرض | کاربرد |
|---|---|---|
| `WHITE_APP_DIR` | `/opt/WhitePanel` | مسیر نصب برنامه |
| `WHITE_REPO` | *(تعریف نشده)* | مخزن گیت برای استقرار |
| `WHITE_BRANCH` | `main` | شاخهٔ استقرار |
| `WHITE_INSTALLER_URL` | آدرس `start.sh` پروژه | منبع اینستالر |
| `WHITE_UV_VERSION` | `0.12.9` | نسخهٔ uv مورد استفاده |
| `WHITE_XRAY_VERSION` | `26.3.27` | نسخهٔ Xray مورد استفاده |

```bash
# استقرار شاخهٔ دلخواه در مسیر دلخواه
WHITE_APP_DIR=/opt/WhitePanel WHITE_BRANCH=main bash start.sh install
```

> 🔒 رمز و توکن را داخل مخزن کامیت نکنید؛ از Environment یا تنظیمات محافظت‌شدهٔ سرور استفاده کنید.

## گزینه B — Railway

1. مخزن را در حساب GitHub خود Fork کنید.
2. در Railway یک پروژهٔ جدید از همان مخزن بسازید.
3. بگذارید Railway با `Dockerfile` و `railway.toml` بیلد کند.
4. پورت برنامه را روی **`8080`** قرار دهید.
5. یک دامنهٔ عمومی بسازید.
6. با همان دامنه وارد پنل شوید.

### نکات مهم Railway

- فرایند برنامه روی `0.0.0.0:8080` گوش می‌دهد.
- `railway.toml` همان پورت ثابت را به Uvicorn می‌دهد.
- کشف دامنهٔ عمومی مهم است: لینک اشتراک و لینک‌های کاربری از آن ساخته می‌شوند.
- هرگز `localhost` را به‌عنوان دامنهٔ عمومی اشتراک استفاده نکنید.

# 🧭 اندپوینت عمومی و جریان اشتراک

WhitePanel ابزارهای Runtime/اندپوینت عمومی دارد تا وقتی دامنهٔ نهایی *بعد از* استقرار مشخص شد، پنل همچنان درست کار کند.

```text
Panel
  ├─ /white                → پنل اصلی
  ├─ /login                → صفحهٔ ورود
  ├─ /dashboard            → داشبورد
  ├─ /link/<uuid>          → صفحهٔ لینک کاربر
  ├─ /p/<uuid_key>         → صفحهٔ عمومی اشتراک
  └─ /api/sub/<uuid_key>   → اندپوینت اشتراک
```

اندپوینت‌های QR هم برای تحویل کانفیگ اشتراک/کاربر وجود دارند.

---

# 🤖 اتوماسیون تلگرام

WhitePanel برای مدیریت، عملیات کانال و فروش، فرایندهای تلگرامی آماده دارد.

### کانال بات

جریان کانال بات می‌تواند کاربر جدید بسازد، اشتراک + QR را تولید کند، محتوا را در کانال منتشر کند و بعد از تحویل موفق، پاک‌سازی مربوطه را انجام دهد.

### بات فروش

مسیر مشتری عمداً ساده است — سادگی یعنی فروش بیشتر:

```text
🟢 اعتبار من   →   🛍 محصولات   →   💬 پشتیبانی
```

هر پلن مستقل تعریف می‌شود و نام، قیمت، اینباند، سهمیهٔ حجم، مدت و پیشوند کاربر خودش را دارد.

جریان خرید:

```text
/start
   ↓
🛍 محصولات
   ↓
انتخاب پلن
   ↓
اطلاعات پرداخت
   ↓
ارسال رسید
   ↓
بررسی ادمین
   ├─ ✅ تأیید → اشتراک + QR
   └─ ❌ رد
```

قابلیت‌های تکمیلی: بررسی عضویت اجباری کانال، شناسهٔ عددی ادمین تلگرام، مدیریت پلن‌ها و مدیریت انقضا.

# 🛡 حساب، اعتبار و تحویل

### هویت حساب

جریان فروش تلگرام هر مشتری را با **شناسهٔ عددی تلگرام** مرتبط می‌کند. حساب‌های موجود به‌جای ساخت نسخهٔ تکراری، به‌روزرسانی می‌شوند و فعال‌سازی سفارش طوری طراحی شده که یک خرید دوبار اعمال نشود.

### انقضا

وقتی زمان اعتبار کاربر می‌رسد، expiry sweeper تلاش می‌کند حساب را حذف، نگاشت تلگرام را پاک و سپس اتمام اعتبار را به کاربر اعلام کند.

### ایمنی تحویل

فعال‌سازی و تحویل عمداً از هم جدا شده‌اند؛ بنابراین یک خطای موقت تلگرام یعنی **کاربر تکراری ساخته نشده** و یک حساب قبلی به‌اشتباه حذف‌شده گزارش نشده است.

---

# 🔎 اسکنر

بخش اسکنر ابزارهای زیر را دارد:

- بررسی TCP / IP
- دادهٔ زیرشبکه‌های Cloudflare
- لیست و بررسی SNI
- مدیریت نتایج اسکن IP/SNI
- پینگ دسته‌ای
- پیدا کردن سریع‌ترین نتیجه

رابط موبایل برای نتایج فشرده و لمسی تنظیم شده تا دامنه یا IP را مستقیم لمس و کپی کنید.

---

# 🌐 نود و ورکر

ابزارهای نود و ورکر شامل بررسی سلامت، Refresh، Sync، راه‌اندازی ورکر و ابزارهای Heartbeat است.

# 📁 ساختار پروژه

```text

├── data/                   # داده‌ها و لیست‌ها

├── railway.toml
├── requirements.txt
├── start.sh                # اینستالر VPS
├── main.py                 # هستهٔ FastAPI
└── README.md
```

# ⚙️ اجرا و API

بک‌اند با **FastAPI / Uvicorn** ساخته شده و اندپوینت‌های احراز هویت، کاربران، اشتراک، نود، اسکنر، ورکر، تنظیمات بات تلگرام و اطلاعات Runtime را دارد.

دیکر Docker پنل را روی این آدرس باز می‌کند:

```text
0.0.0.0:8080
```

برای استقرار تمیز، دامنهٔ عمومی پلتفرم را به همین پورت برنامه متصل کنید.

---

# 🎨 جزئیات رابط کاربری

رابط بر پایهٔ این‌ها ساخته شده:

- حالت تیره/روشن واکنش‌گرا — پایهٔ کاملاً مشکی با اکسنت فیروزه‌ای `#00e1c1`
- تعامل‌های فشرده و لمسی
- اکشن‌های کپی‌محور برای کانفیگ‌ها
- بخش‌های جمع‌شونده
- صفحات اشتراک با تحویل QR
- استایل دکمه‌های شیشه‌ای تلگرام
- چیدمان دسکتاپ + موبایل

پوشهٔ `svg/` شامل تصاویر اصلی مستندات است؛ فایل‌های SVG مستقل‌اند تا هویت بصری پروژه بدون اسکرین‌شات رستری حفظ شود — و رنگ‌بندی‌شان با تم زندهٔ پنل هماهنگ است.

# 🔐 نکات امنیتی

- توکن بات، رمز عبور، API Key و اطلاعات حساس را کامیت نکنید.
- مقادیر حساس را در Environment یا تنظیمات محافظت‌شده نگه دارید.
- برای دسترسی عمومی از HTTPS استفاده کنید.
- دسترسی ادمین را محدود نگه دارید.
- لینک اشتراک را قبل از انتشار عمومی بررسی کنید.

# 🧑‍💻 توسعه

برای اجرای محلی:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m uvicorn main:app --host 0.0.0.0 --port 8080
```

سپس باز کنید:

```text
http://127.0.0.1:8080/white
```

برای تولید و اشتراک عمومی، در لینک‌های کاربری از دامنهٔ واقعی استفاده کنید، نه `localhost`.
